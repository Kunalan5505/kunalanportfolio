# Kunalan Mahendran — Portfolio 2026

Static portfolio website built for GitHub Pages.

## Files
- `index.html` — portfolio content
- `styles.css` — responsive styling
- `script.js` — menu, scroll reveal and small interactions
- `Kunalan-Mahendran-Resume-2026.pdf` — downloadable resume

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `kunalan-portfolio`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will provide the live URL after deployment.

## Customize later
- Add real screenshots to an `assets/` folder.
- Turn each project into a deeper case-study page once confidential information has been removed.
- If desired, connect a custom domain later.
